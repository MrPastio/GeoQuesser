# GeoQuesser

Браузерная игра: по фото с улицы угадай, где оно снято. Бесплатно, без ключей и регистрации.

- **Фото и панорамы 360°:** открытый каталог [Panoramax](https://panoramax.fr) (STAC API `api.panoramax.xyz`, CC BY-SA).
- **Карта:** Leaflet и тайлы OpenStreetMap.
- **Просмотр:** Pannellum (WebGL). Если WebGL нет, включается простой просмотрщик (`js/flatview.js`).

## Возможности

- Регионы: весь мир, Европа, Россия и СНГ, обе Америки, Азия, Африка, Океания, Франция.
- 3, 5 или 10 раундов, таймер, режим «только 360°», ходьба по маршруту съёмки (◀ ▶ ⌂).
- Очки до 5000 за раунд. Масштаб зависит от размера региона: в «мире» за 2000 км даётся ~37%.
- Вызов другу: после игры появляется ссылка с теми же местами.
- Лучшие результаты хранятся в браузере (`localStorage`).

## Запуск

Сборка не нужна, это статический сайт. Из папки проекта:

```bash
python3 -m http.server 8080
```

Затем открыть http://localhost:8080. Можно выложить как есть на GitHub Pages или любой статический хостинг.

## Устройство

- `js/app.js`: игровой цикл, поиск места, загрузка снимков, подсчёт очков, вызовы.
- `js/regions.js`: рамки суши для регионов и их веса.
- `js/flatview.js`: запасной просмотрщик без WebGL.

Случайное место: берётся случайная точка в рамках региона, у Panoramax запрашиваются снимки рядом.
Снимок скачивается заранее; битые (≈2% в каталоге) отсеиваются, вместо них берётся другой.
